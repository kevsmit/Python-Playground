# Number Base Converter

A small script that converts a whole number between binary, octal, decimal and hex.

## How to run

```
python base_converter.py <number> <from_base>
```

Example:

```
python base_converter.py FF 16
```

Output:

```
Decimal: 255
Binary:  11111111
Octal:   377
Hex:     FF
```
