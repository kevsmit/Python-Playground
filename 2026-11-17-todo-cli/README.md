# To-Do CLI

A small to-do list you run from the terminal. Items are saved to
`todos.json` next to the script so they stick around between runs.

## Run

    python todo.py add buy milk
    python todo.py add call mom
    python todo.py            # show the list
    python todo.py done 1     # check off item 1
    python todo.py remove 2   # delete item 2
    python todo.py clear      # remove everything that's done
