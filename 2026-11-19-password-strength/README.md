# Password Strength Checker

Rates a password as weak, ok or strong and tells you what would make it better.
It looks at length, whether it mixes lowercase, uppercase, numbers and symbols,
and whether it's one of the really common passwords.

What you type is hidden and nothing is saved.

## Run

    python strength.py

Example:

    Password to check (hidden):
    Strength: ok (4/6)
     - add a number
     - add a symbol
