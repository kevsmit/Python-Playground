# Maze Solver

Finds the shortest way through a text maze using breadth-first search
and marks the path with `*`.

`#` is a wall, `.` is open space, `S` is the start and `E` is the exit.

## Run

    python maze_solver.py

That solves the built-in maze. You can also pass your own maze file:

    python maze_solver.py my_maze.txt
