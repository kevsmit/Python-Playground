# Python Playground

A collection of small, finished Python projects and useful scripts.

## Project 001: Network Troubleshooter

`001_network_troubleshooter.py` runs a few common network checks in one place:

- Shows the computer name and local IP address
- Tests DNS resolution
- Tests whether common web ports can be reached
- Pings a reliable public IP
- Prints a clear summary of what passed and failed

### Run it

```bash
python 001_network_troubleshooter.py
```

It uses only Python's standard library, so there is nothing extra to install.
