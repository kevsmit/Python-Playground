# Bracket Checker

Checks whether the `()`, `[]` and `{}` in some text are balanced.
If they aren't, it tells you where the problem is.

## Run

    python brackets.py              # type the text in
    python brackets.py notes.txt    # check a whole file

Example:

    Enter some text: (a [b) c]
    Not balanced: '[' at position 3 closed by ')' at position 5
